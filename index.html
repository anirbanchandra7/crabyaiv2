Frequently asked questions.

Something we missed? Talk to an engineer, not a sales script.

What does "own your intelligence" actually mean?
The fine-tuned version of your model is yours. Your data only ever trains your model, never anyone else's, and you can export your weights whenever you like. No lock-in, no hostage situation.
Which models can I deploy?
The leading open-weight families, including Llama, Qwen, Mistral, Gemma, DeepSeek and gpt-oss, from small fast models to 100B+ parameters. New releases usually land within days.
How does Privacy Protect work?
Every prompt passes through a detection layer before it reaches the model. Sensitive values are replaced with typed placeholders, the model writes its answer, and Craby restores the real values in the response for authorised users only. The model never sees the originals.
How does the model get smarter over time?
You decide which conversations count as training data. Craby fine-tunes a candidate on them, scores it against your evaluation set, and promotes it only if it wins. Every version is kept, so rolling back takes one click.
How does billing work?
Add credit, then pay per token at the rate for your model's size. There are no seat fees and no minimum spend. Turn on auto-recharge and set spend limits per team so nothing surprises you.
Will my existing code work?
Yes. The endpoint is OpenAI-compatible, so most apps move over by changing the base URL and the API key.
